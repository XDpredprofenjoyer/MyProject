# predprof_444_stolovka

Проект включает в себя разработку системы управления столовой и выбор ролей при регистрации:
- Повар - видит заявки, оставшиеся блюда и учет. 
- Студент - заказывает еду на завтрак или обед (обязательно на определенную дату), если нужно, указывает аллергены и оплачивает корзину. 
- Админ - видит посещаемость,заявки на выбранную дату и отчет по заказам.

## Инструкция по установке:

Проект хранится в репозитории (см. ссылку внизу страницы). Необходимые для запуска библиотеки перечислены в файле requirements.txt. Для фронтенда нужно скачать файл index(1).html.
